DISTRIBUTION AND SUPPORT

 

Our website is hosted by isonews.com, your favorite public website for ISO information. pdSFV's latest version is available at

http://pdsfv.isonews.com

and distributed with full source and documentation. The windows version was written in Object Pascal (Delphi 5), the Unix/Linux one in ANSI C. It should be readable and understandable also by novice programmers.

pdSFV is, as the name says, public domain software. This means there's no copyright claimed by any of its programmers and you're free to do with the source whatever you want to do - like making a SFV tool yourself. We're just asking you that you do not distribute self-made or modified versions as "pdSFV" without properly stating that it is not the original version and what you have changed in it.

Spreading the whole source with a program tends to be abused by bored kids which might have some fun putting a trojan into the program and redistribute their modified version as original pdSFV. Thus, if you have not downloaded this package from the official website or any other site you trust, make sure to check out the official website, since the SFV CRC value of the currently original distribution archive will be listed there so you can make sure that you don't have a fake.

Isonews.com has discussion forums where problems with pdSFV can be discussed. Though you may figure out that the programmers don't show up much in public you can be sure that often-stated wishes, suggestions and bug reports will be heard and contribute to successing versions. Please forgive our customer-unfriendliness but due to constant lack of time we currently do not provide any way of direct support.

 

Thanks for choosing pdSFV!
